# superQ 待评估功能清单

## 1. 行情数据完整性

- 当前数据库还不是 5510 只全市场完整 K 线。
- 当前已按要求改回只使用东方财富接口：`ak.stock_zh_a_hist(...)`。
- 风险：东财接口之前出现过断连、反爬、代理异常，可能导致全量同步较慢或失败。

## 2. 新闻策略增强

已完成：

- 新闻缓存库 `news_items`。
- 近 7 天新闻过滤。
- 本地股票名称映射表 `stock_names`。
- 风险词过滤。

待评估：

- 新闻情绪打分。
- 题材热度打分。
- 事件类型识别。
- 综合评分排序。

## 3. 新闻与股票关联能力

当前：

- 主要通过股票代码、股票名称、关键词字符串匹配。

待评估：

- 同义词词库。
- 概念板块映射。
- 产业链词库。
- 股票简称歧义处理。

## 4. 推送内容增强

当前：

- 飞书推送主要展示股票列表。

待评估：

- 展示命中的新闻标题。
- 展示风险过滤原因。
- 展示命中的技术策略来源。
- 展示综合分数。
- 展示近 7 天相关新闻摘要。

## 5. 策略回测

当前：

- 只支持按最新数据筛选。

待评估：

- 指定历史日期回放。
- 策略收益统计。
- 胜率统计。
- 最大回撤统计。
- 策略之间对比。

## 6. 配置化

当前：

- `NEWS_LOOKBACK_DAYS` 默认支持 7 天。

待评估：

- 策略开关。
- 策略阈值配置。
- 是否发送飞书开关。
- 新闻源开关。
- 新闻缓存保留天数配置。

## 7. 数据库维护

当前：

- 新闻会缓存到 SQLite。
- 股票名称映射已补充全量 5510 条。

待评估：

- 自动清理旧新闻。
- 只保留最近 30/90 天新闻。
- 定期刷新股票名称映射。
- 数据库体积监控。
